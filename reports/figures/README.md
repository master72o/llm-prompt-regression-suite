# Figures Directory

This directory contains visual charts generated by the Prompt Regression Suite:
- `pass_rate_comparison.png`: Pass rate and mean score comparison between Baseline and Candidate versions with CI Quality Gate threshold line.
- `metric_delta_breakdown.png`: Per-test score delta comparison identifying positive performance gains vs negative drop-offs.
- `regression_type_distribution.png`: Donut chart showing breakdown of detected regression categories (Format Breakage, Safety Breach, Latency, Accuracy).
